Werkervaring

Ik heb enkele ervaring in werkcultuur. Als jobstudent heb ik een maand in een kantooromgeving gewerkt. De grootste werkervaring heb ik echter opgedaan in een jaar fabriekswerk, waar ik een echte mentaliteit heb geschapen. Daarnaast heb ik ook een beetje vrijwilligerswerk gedaan als assistent in een rusthuis. Nu ben ik (assistent-)trainer in een judoclub. Ik kan goed zelfstandig werken, maar ik kan ook met collega’s werken als het nodig is.
